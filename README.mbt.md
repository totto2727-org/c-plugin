# c-plugin

Native MoonBit bootstrap for the standalone c-plugin implementation.

The executable uses the public command name `c-plugin`. This migration snapshot preserves the staged v2 implementation and does not include v1.

The [design contract](./docs/design/contract.md) includes planned capabilities and does not imply that every feature is implemented or published.

```bash
moon run ./src --target native -- --help
moon run ./src --target native -- --version
```
